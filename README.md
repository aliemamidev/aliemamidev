## About me

I enjoy turning messy, repetitive workflows into small, reliable products. My public work spans browser extensions, WordPress and WooCommerce, Python automation, Flask applications, security-conscious local tooling, Docker operations, and data export utilities.

My approach is practical:

- Start with the real user workflow
- Keep the interface clear and the setup approachable
- Prefer local-first and privacy-aware designs when the data is sensitive
- Automate repetitive work without hiding what the tool is doing
- Document projects so they remain useful after the first run
